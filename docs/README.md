## Historical evidence

The `phase*.md`, benchmark, calibration, audit, and coupling documents retain
reproduction commands, source attribution, splits, and measured results.
They are intentionally not deleted or silently rewritten as current product
claims. Their status is historical unless a current guide links to them.

For latest implementation status, use the current roadmap and README. For
exact phase evidence, use the corresponding historical document.
