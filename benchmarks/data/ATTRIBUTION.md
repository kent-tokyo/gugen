## How this sample was generated

`python3 benchmarks/fetch_kononova.py` (seed 20260814), filtering 19488 raw reactions down to 8936 eligible entries, then a deterministic downsample to 1500.

Exclusion counts (each reaction excluded for exactly one reason, in this check order):

- Unparseable target (free-variable/doped/disordered formula, or a non-numeric/non-positive amount): 9081
- Unparseable precursor (same criteria, any precursor): 954
- Zero precursors, or more than gugen's default `SearchBudget::max_precursors_per_plan` (4) after de-duplication: 408
- Leakage against a route already used by `tests/validation.rs` or `src/literature_conditions.rs`'s curated records (matched by normalized elemental ratio, not formula string or DOI -- several of these routes are independently reported by dozens of DOIs in this corpus, so DOI-only exclusion would have left near-duplicates in the holdout set): 109

This file and `kononova_sample.jsonl` are regenerated by re-running the script above, not hand-edited.
